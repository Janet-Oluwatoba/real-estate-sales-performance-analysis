# Real Estate Sales Performance and Customer Investment Behavior Analysis in Nigeria

## 📊 Project Overview

This project analyzes real estate transactions in Nigeria to evaluate sales performance, customer investment behavior, payment patterns, property types, regional performance, and revenue trends.

## 🎯 Project Objectives

- Analyze real estate transactions across different regions.
- Evaluate revenue performance by region and real estate company.
- Compare installment and outright payment methods.
- Analyze customer types and property types.
- Identify high-value transactions.
- Examine discounts and their impact on transactions.
- Identify monthly revenue trends.
- Generate insights to support better business decision-making.

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- Data Visualization
- Pivot Tables
- Exploratory Data Analysis (EDA)

## 📁 Dataset

The dataset contains real estate transaction records, including information about:

- Transaction ID
- Transaction Date
- Region
- Property Type
- Customer Type
- Payment Type
- Real Estate Company
- Property Value
- Discount
- Transaction Status
- And other relevant transaction attributes.

## 📈 Key Analysis

The project will explore:

- Revenue by region
- Revenue by real estate company
- Transactions by property type
- Customer composition
- Payment method performance
- Transaction completion rates
- Discount patterns
- High-value transactions
- Monthly revenue trends
